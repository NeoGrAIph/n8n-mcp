## [2.14.4] - 30 сентября 2025 г.

### Добавлен
- **Операции по очистке рабочего процесса**: две новые операции для `n8n_workflow_update_partial` для восстановления нарушенного рабочего процесса.
- `cleanStaleConnections`: автоматически удаляет все соединения, ссылающиеся на несуществующие узлы.
- Важно после переименования или удаления узла, оставляющего висячие ссылки на соединения.
- Поддерживает режим `dryRun: true` для предварительного просмотра того, что будет удалено.
- Удаляет как исходные, так и целевые устаревшие соединения.
- `replaceConnections`: замена всего объекта соединений за одну операцию.
- Быстрее, чем выполнять множество отдельных операций подключения.
- Полезно для перемонтажа массовых соединений.

- **Надежная обработка ошибок при операциях подключения**: улучшенная операция `removeConnection`.
- Новый флаг `ignoreErrors`: при `true` операция завершается успешно, даже если соединение не существует.
- Идеально подходит для сценариев очистки, когда вы не уверены в наличии соединений.
- Поддерживает обратную совместимость (по умолчанию `false` для строгой проверки)

- **Режим Best Effort**: новый режим `continueOnError` для `WorkflowDiffRequest`.
- Применяйте допустимые операции, даже если некоторые из них терпят неудачу.
- Возвращает подробные результаты с индексами операций `applied` и `failed`.
- Намеренно нарушает атомные гарантии для сценариев массовой очистки.
- Поддерживает атомный режим по умолчанию в целях безопасности.

### Улучшенный
- **Документация по инструменту**: обновлена ​​документация `n8n_workflow_update_partial`.
- Добавлены примеры сценариев очистки.
- Документированы новые типы и режимы работы.
- Добавлены рекомендации по восстановлению рабочего процесса.
- Уточнено атомарное поведение по сравнению с поведением с максимальными усилиями.

- **Система типов**: расширенные типы различий рабочего процесса.
- Добавлен интерфейс `CleanStaleConnectionsOperation`.
- Добавлен интерфейс `ReplaceConnectionsOperation`.
- Расширен `WorkflowDiffResult` с полями `applied`, `failed` и `staleConnectionsRemoved`.
- Обновлены типы защиты для новых операций подключения.

### Тестирование
- Добавлен комплексный набор тестов для функций версии 2.14.4.
- 15 новых тестов, охватывающих все новые операции и режимы
- Тесты на cleanStaleConnections с различными устаревшими сценариями.
- Тесты для проверки replaceConnections
- Тесты на поведение флага ignoreErrors.
- Тесты для режима continueOnError со смешанным успехом/неуспехом.
- Тесты проверки обратной совместимости.

### Влияние
- **Экономия времени**: время исправления сбоев рабочего процесса сокращается с 10–15 минут до 30 секунд.
- **Эффективность токена**: `cleanStaleConnections` — 1 операция против 10+ ручных операций.
- **Удобство использования**: значительно улучшены возможности восстановления рабочего процесса.
- **Обратная совместимость**: 100 % – все дополнения являются необязательными и по умолчанию соответствуют существующему поведению.

## [2.13.2] - 24.01.2025

- Фильтрация операций с учетом ресурсов обеспечивает контекстуальность предложений.
